# BookFlow

## Используемые технологии
- Python
- Git и GitHub
- Markdown
- PlantUML

В проекте реализована реляционная база данных на основе СУБД **SQLite**.

### Структура базы данных и связи
База данных включает в себя следующие таблицы:
* **`authors`** — таблица для хранения информации об авторах.
* **`books`** — таблица книг, связанная с авторами отношением **один-ко-многим (1:N)** через внешний ключ `author_id`.
* **`members`** — список зарегистрированных участников (читателей).
* **`loans`** — таблица учета аренды и бронирования книг, связывающая участников и книги.

# BookFlow

**BookFlow** — консольное приложение для управления библиотекой. Проект предназначен для автоматизации основных процессов работы с библиотечным фондом и читателями. Приложение позволяет регистрировать пользователей, выполнять авторизацию и работать с данными библиотеки, включая книги, авторы и бронирования.

---

## Возможности

В проекте реализованы следующие основные возможности:

* Регистрация читателей
* Авторизация пользователей
* Управление пользователями
* Работа с книгами
* Работа с авторами
* Хранение связи между книгами и авторами
* Бронирование книг
* Управление статусами бронирования
* Хранение данных в базе данных
