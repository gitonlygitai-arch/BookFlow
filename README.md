# GitExample

## О проекте
Учебный проект, созданный в рамках лабораторной работы №2. Программа написана на языке Python и выполняет базовый вывод текста на экран.

## Как запустить
1. Откройте проект в VS Code.
2. Запустите файл с кодом через встроенный терминал (например, командой python main.py).

## Используемые технологии
- Python
- Git и GitHub
- Markdown
- PlantUML

## Лабораторная работа №3: Проектирование и реализация базы данных

В проекте реализована реляционная база данных на основе СУБД **SQLite**.

### Структура базы данных и связи
База данных включает в себя следующие таблицы:
* **`authors`** — таблица для хранения информации об авторах.
* **`books`** — таблица книг, связанная с авторами отношением **один-ко-многим (1:N)** через внешний ключ `author_id`.
* **`members`** — список зарегистрированных участников (читателей).
* **`loans`** — таблица учета аренды и бронирования книг, связывающая участников и книги.

### ER-диаграмма
Графическая схема базы данных и проектные материалы сохранены в папке **`diagrams/`**.
